# 🍺 World Book Search

给 SillyTavern 的**世界书编辑面板**加一条搜索栏 —— 独立结果面板、可直接编辑、命中高亮、批量替换。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🔍 实时搜索 | 边打字边搜，独立结果面板，**完全不干预原生条目列表** |
| 🎛️ 范围可选 | 备注 / 关键词(keys) / 内容(content) 任意组合 |
| 📋 独立结果面板 | 毛玻璃质感卡片，条目名 + 命中字段 + 上下文片段 |
| 🖍️ 命中高亮 | 关键词柔和高亮 + 下划线 |
| ✏️ **直接编辑** | 点结果卡片 → 展开编辑区 → 改完自动同步 |
| 💾 **一键保存** | 改完点保存按钮写回酒馆（也可用批量替换自动保存） |
| ⌖ 快速定位 | 卡片右侧定位按钮，滚动到原生条目并闪烁标记 |
| 🔧 面板内诊断 | 点右上角扳手，直接在面板里看数据情况，不用开 F12 |
| 🔁 批量替换 | 一键把关键词换成别的词（带二次确认，自动保存） |

## 📥 安装

酒馆 → 扩展（Extensions）→ Install extension → 粘贴：

```
https://github.com/xyo-ovo/Worldbook-Search
```

装完按 `Ctrl + F5` 刷新整个页面。

## 🎮 用法

1. 打开任意角色的「世界书」编辑窗口（选中一本世界书）
2. 条目列表上方会多出一条搜索栏
3. 输入关键词 → 下方出现独立结果面板，命中处高亮
4. **点结果卡片** → 原地展开编辑区，直接改内容
5. 改完点 **💾 保存** 写回酒馆
6. 想批量改 → 展开「批量替换」（自动保存）

## 🩺 读不到数据怎么办

点搜索面板右上角的 **🔧** 按钮，会显示：

- `context.loadWorldInfo` / `saveWorldInfo` 有没有
- 当前选中的世界书名
- 读到的条目数 + 前 3 条的字段长度

（也可以在控制台执行 `wbSearchDebug()`）

## ⚠️ 注意事项

- 🔎 搜索范围是**当前打开的那本世界书**
- 💾 改完记得点 **💾 保存**（批量替换会自动保存）
- 🧱 依赖酒馆的 `loadWorldInfo` / `saveWorldInfo` API（现代版本都有）
