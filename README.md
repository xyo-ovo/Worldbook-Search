# 🍺 World Book Search

给 SillyTavern 的**世界书编辑面板**加一条搜索栏 —— 完全独立的结果面板、可直接编辑、命中高亮、批量替换。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🔍 实时搜索 | 边打字边搜，独立结果面板，**完全不干预原生条目列表** |
| 🎛️ 范围可选 | 备注 / 关键词(keys) / 内容(content) 任意组合 |
| 📋 独立结果面板 | 毛玻璃质感卡片，条目名 + 命中字段 + 上下文片段 |
| 🖍️ 命中高亮 | 关键词柔和高亮 + 下划线，一眼看到命中位置 |
| ✏️ **直接编辑** | 点结果卡片 → 展开编辑区 → 改完自动同步回原生条目 |
| ⌖ 快速定位 | 卡片右侧定位按钮，滚动到原生条目并闪烁标记 |
| 🔁 批量替换 | 一键把关键词换成别的词（带二次确认） |

## 📥 安装

**方式一：链接安装（推荐）**

酒馆 → 扩展（Extensions）→ Install extension → 粘贴：

```
https://github.com/xyo-ovo/Worldbook-Search
```

装完按 `Ctrl + F5` 刷新整个页面。

**方式二：手动放**

丢进 `SillyTavern/public/scripts/extensions/third-party/Worldbook-Search/`，然后 `Ctrl + F5`。

## 🎮 用法

1. 打开任意角色的「世界书」编辑窗口
2. 条目列表上方会多出一条搜索栏
3. 输入关键词 → 下方出现独立结果面板，命中处高亮
4. **点结果卡片** → 原地展开编辑区，直接改内容（自动同步）
5. 想跳回原生条目看看 → 点卡片右侧的 ⌖ 按钮
6. 想批量改 → 展开「批量替换」

## 🩺 搜不到东西怎么办

按 `F12` 打开控制台，输入下面这行回车：

```js
wbSearchDebug()
```

它会把第一个条目的 HTML 结构和收集到的字段文本打印出来。把输出贴给开发者，就能精确适配你的酒馆版本。

## ⚠️ 注意事项

- 🔎 搜索范围是**当前打开的那本世界书**，不是全部世界书
- 💾 在结果面板里改完，记得点世界书面板的**保存按钮**才会真正落盘
- 🧱 如果酒馆大版本更新改了界面结构，可能需要跟着调整选择器
