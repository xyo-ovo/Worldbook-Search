# 🍺 World Book Search

给 SillyTavern 的**世界书编辑面板**加一条搜索栏 —— 实时过滤条目、命中徽章、批量替换关键词。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🔍 实时搜索 | 边打字边过滤，命中的条目立刻显示 |
| 🎛️ 范围可选 | 备注 / 关键词(keys) / 内容(content) 任意组合 |
| 👁️ 只显示匹配 | 关掉就是「高亮但不隐藏」 |
| 🏷️ 命中徽章 | 条目顶上挂 `🔍 内容 / 关键词` 小标签 |
| ✏️ 就地编辑 | 过滤出来后直接在原 textarea 里改 |
| 🔁 批量替换 | 一键把关键词换成别的词（带二次确认） |

## 📥 安装

**方式一：链接安装（推荐）**

酒馆 → 扩展（Extensions）→ Install extension → 粘贴：

```
https://github.com/xyo-ovo/Worldbook-Search
```

装完按 `Ctrl + F5` 刷新整个页面。

**方式二：手动放**

丢进 `SillyTavern/public/scripts/extensions/third-party/Worldbook-Search/`，然后 `Ctrl + F5`。

## 🎮 用法

1. 打开任意角色的「世界书」编辑窗口
2. 条目列表上方会多出一条搜索栏
3. 输入关键词 → 实时过滤
4. 找到后直接在条目里改，酒馆会自动同步
5. 想批量改就展开「🔁 批量替换」

## ⚠️ 注意事项

- 🔎 搜索范围是**当前打开的那本世界书**，不是全部世界书
- 💾 改完记得点世界书面板的**保存按钮**，本插件只帮你改 textarea 的值
- 🧱 如果酒馆大版本更新改了界面结构，可能需要跟着调整选择器（`index.js` 里的 `FIELDS` 已写多套兜底）
