# 🍺 World Book Search

给 SillyTavern 的**世界书编辑面板**加一条搜索栏 —— 独立的搜索结果列表、命中高亮、一键跳转、批量替换。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 🔍 实时搜索 | 边打字边搜，有自己的结果面板，不改动原生条目列表 |
| 🎛️ 范围可选 | 备注 / 关键词(keys) / 内容(content) 任意组合 |
| 📋 独立结果列表 | 每条结果显示条目名 + 命中的字段 + 上下文片段 |
| 🖍️ 命中高亮 | 关键词用主题色高亮，像被选中那样醒目 |
| 🖱️ 点击跳转 | 点结果自动滚动到对应条目并闪一下定位 |
| 🔁 批量替换 | 一键把关键词换成别的词（带二次确认） |

## 📥 安装

**方式一：链接安装（推荐）**

酒馆 → 扩展（Extensions）→ Install extension → 粘贴：

```
https://github.com/xyo-ovo/Worldbook-Search
```

装完按 `Ctrl + F5` 刷新整个页面。

**方式二：手动放**

丢进 `SillyTavern/public/scripts/extensions/third-party/Worldbook-Search/`，然后 `Ctrl + F5`。

## 🎮 用法

1. 打开任意角色的「世界书」编辑窗口
2. 条目列表上方会多出一条搜索栏
3. 输入关键词 → 下方出现独立的结果列表，命中处高亮
4. 点任意结果 → 自动滚动到原生条目并闪烁定位
5. 想批量改就展开「🔁 批量替换」

## 🔧 更新日志

- **v1.2.0** — 新增**独立搜索结果面板**：不再依赖原生条目的显隐来展示结果，改为自己的结果列表（条目名 + 命中字段 + 上下文片段 + 关键词高亮），支持点击跳转定位；原生日志列表默认不动
- **v1.1.0** — 字段识别改成「多路兜底」策略，修复某些酒馆版本下所有条目都搜不到（命中 0/N）的问题；新增控制台诊断命令 `wbSearchDebug()`
- **v1.0.0** — 初版：实时搜索 + 命中徽章 + 批量替换

## 🩺 搜不到东西怎么办

按 `F12` 打开控制台，输入下面这行回车：

```js
wbSearchDebug()
```

它会把第一个条目的 HTML 结构和收集到的字段文本打印出来。把输出贴给开发者，就能精确适配你的酒馆版本。

## ⚠️ 注意事项

- 🔎 搜索范围是**当前打开的那本世界书**，不是全部世界书
- 💾 改完记得点世界书面板的**保存按钮**，本插件只帮你改输入框的值
- 🧱 如果酒馆大版本更新改了界面结构，可能需要跟着调整选择器
